# Biblioteca_en_L-nea_Seguridad_de_base_de_datos
Biblioteca virtual educativa orientada a la asignatura Seguridad de Base de Datos. Contiene recursos académicos, guías, talleres y materiales sobre ciberseguridad, gestión de privilegios, encriptación, auditoría y protección de bases de datos, promoviendo el aprendizaje colaborativo mediante GitHub.
